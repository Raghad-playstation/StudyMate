# StudyMate

## Project Overview

StudyMate is a web-based task management system designed to help students organize their academic tasks, manage deadlines, and track their progress through an interactive dashboard.

This project was developed as part of the CS486 Web Application Development course at Princess Nourah bint Abdulrahman University.

## Features

- User registration and authentication.
- Secure password hashing and session management.
- Create, view, edit, and delete tasks.
- Assign task priorities: High, Medium, and Low.
- Track task status: Pending or Completed.
- Search and filter tasks dynamically.
- Interactive dashboard with task statistics.
- View upcoming deadlines.
- Client-side and server-side validation.
- Dynamic updates using AJAX.

## Technologies Used

| Technology | Purpose |
|---|---|
| HTML5 | Website structure |
| CSS3 | Styling and user interface |
| JavaScript | Client-side functionality |
| AJAX | Asynchronous data retrieval and updates |
| PHP | Server-side logic |
| MySQL | Database management |
| PDO | Database connectivity and prepared statements |
| XAMPP | Local development environment |

## Installation and Setup

1. Clone the repository.
2. Place the StudyMate folder inside the XAMPP `htdocs` directory.
3. Start Apache and MySQL using the XAMPP Control Panel.
4. Create a MySQL database named `studymate_db`.
5. Import the database schema.
6. Configure the database connection in `db_connect.php`.
7. Open the application in your browser at `http://localhost/StudyMate/`.
